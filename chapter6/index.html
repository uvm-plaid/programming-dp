Approximate Differential Privacy

Learning Objectives

After reading this chapter, you will be able to:

  • Define approximate differential privacy

  • Explain the differences between approximate and pure differential privacy

  • Describe the advantages and disadvantages of approximate differential privacy

  • Describe and calculate L1 and L2 sensitivity of vector-valued queries

  • Define and apply the Gaussian mechanism

  • Apply advanced composition

Approximate differential privacy Dwork et al. (2006), also called (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy, has the following definition:

Definition 1 (Approximate Differential Privacy)
Pr[F(x)=S]≤eϵPr[F(x′)=s]+δ\begin{align*} \mathsf{Pr}[F(x) = S] \leq e^\epsilon \mathsf{Pr}[F(x') = s] + \delta \end{align*}Pr[F(x)=S]≤eϵPr[F(x′)=s]+δ​
(1)

The new privacy parameter, δ\deltaδ, represents a “failure probability” for the definition. With probability 1−δ1-\delta1−δ, we will get the same guarantee as pure differential privacy; with probability δ\deltaδ, we get no guarantee. In other words:

  • With probability 1−δ1-\delta1−δ, Pr[F(x)=S]Pr[F(x′)=s]≤eϵ\frac{\mathsf{Pr}[F(x) = S]}{\mathsf{Pr}[F(x') = s]} \leq e^\epsilonPr[F(x′)=s]Pr[F(x)=S]​≤eϵ

  • With probability δ\deltaδ, we get no guarantee at all

This definition should seem a little bit scary! With probability δ\deltaδ, anything at all could happen - including a release of the entire sensitive dataset! For this reason, we typically require δ\deltaδ to be very small - usually 1n2\frac{1}{n^2}n21​ or less, where nnn is the size of the dataset. In addition, we’ll see that the (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differentially private mechanisms in practical use don’t fail catastrophically, as allowed by the definition - instead, they fail gracefully, and don’t do terrible things like releasing the entire dataset.

Such mechanisms are possible, however, and they do satisfy the definition of (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy. We’ll see an example of such a mechanism later in this section.

Properties of Approximate Differential Privacy¶

Approximate differential privacy has similar properties to pure ϵ\epsilonϵ-differential privacy. It satisfies sequential composition:

Theorem 1 (Approximate Sequential Composition)

  • If F1(x)F_1(x)F1​(x) satisfies (ϵ1,δ1)(\epsilon_1, \delta_1)(ϵ1​,δ1​)-differential privacy

  • And F2(x)F_2(x)F2​(x) satisfies (ϵ2,δ2)(\epsilon_2, \delta_2)(ϵ2​,δ2​)-differential privacy

  • Then the mechanism G(x)=(F1(x),F2(x))G(x) = (F_1(x), F_2(x))G(x)=(F1​(x),F2​(x)) which releases both results satisfies (ϵ1+ϵ2,δ1+δ2)(\epsilon_1+\epsilon_2, \delta_1 + \delta_2)(ϵ1​+ϵ2​,δ1​+δ2​)-differential privacy

The only difference from the pure ϵ\epsilonϵ setting is that we add up the δ\deltaδs as well as the ϵ\epsilonϵs. Approximate differential privacy also satisfies post-processing and parallel composition.

Note

The parameter δ \delta δ, like ϵ \epsilon ϵ, is immune to change under post-processing: applying any function to the output of a (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differentially private mechanism cannot increase the privacy loss.

Under parallel composition, where disjoint subsets of data are each analyzed with (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy, the overall result remains (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differentially private—meaning δ \delta δ does not accumulate as long as the datasets are disjoint.

The Gaussian Mechanism¶

The Gaussian mechanism is an alternative to the Laplace mechanism, which adds Gaussian noise instead of Laplacian noise. The Gaussian mechanism does not satisfy pure ϵ\epsilonϵ-differential privacy, but does satisfy (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy. According to the Gaussian mechanism, for a function f(x)f(x)f(x) which returns a number, the following definition of F(x)F(x)F(x) satisfies (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy:

Definition 2 (Gaussian Mechanism)
F(x)=f(x)+N(σ2)where σ2=2s2log⁡(1.25/δ)ϵ2\begin{align*} F(x) = f(x) + \mathcal{N}(\sigma^2)\\ \text{where } \sigma^2 = \frac{2s^2 \log(1.25/\delta)}{\epsilon^2} \end{align*}F(x)=f(x)+N(σ2)where σ2=ϵ22s2log(1.25/δ)​​
(2)

where sss is the sensitivity of fff, and N(σ2)\mathcal{N}(\sigma^2)N(σ2) denotes sampling from the Gaussian (normal) distribution with center 0 and variance σ2\sigma^2σ2. Note that here (and elsewhere in these notes), log⁡\loglog denotes the natural logarithm.

For real-valued functions f:D→Rf : D \rightarrow \mathbb{R}f:D→R, we can use the classic Gaussian mechanism with values of ϵ\epsilonϵ equal to or less than 1, a range called "high privacy"Balle & Wang (2018). This is in contrast to the Laplace mechanism, which can be used in any privacy regime, high or low.

It’s easy to compare what happens under both mechanisms for a given value of ϵ\epsilonϵ.

So the Gaussian mechanism has two major drawbacks - it requires the use of the the relaxed (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy definition, and it’s less accurate than the Laplace mechanism. Why would we want to use it?

Vector-Valued Functions and their Sensitivities¶

So far, we have only considered real-valued functions (i.e. the function’s output is always a single real number). Such functions are of the form f:D→Rf : D \rightarrow \mathbb{R}f:D→R. Both the Laplace and Gaussian mechanism, however, can be extended to vector-valued functions of the form f:D→Rkf : D \rightarrow \mathbb{R}^kf:D→Rk, which return vectors of real numbers. We can think of histograms as vector-valued functions, which return a vector whose elements consist of histogram bin counts.

We saw earlier that the sensitivity of a function is:

GS(f)=max⁡d(x,x′)≤1∣f(x)−f(x′)∣\begin{align} GS(f) = \max_{d(x,x') \leq 1} \lvert f(x) - f(x') \rvert \end{align}GS(f)=d(x,x′)≤1max​∣f(x)−f(x′)∣​​
(3)

How do we define sensitivity for vector-valued functions?

Consider the expression f(x)−f(x′)f(x) - f(x')f(x)−f(x′). If fff is a vector-valued function, then this expression represents the difference between two vectors, which can be computed as the difference between their corresponding elements (the difference of two length-kkk vectors is thus a new length-kkk vector). This new vector is the distance between f(x)f(x)f(x) and f(x′)f(x')f(x′), represented as a vector.

The magnitude of this vector is the sensitivity of fff. There are several ways to compute the magnitude of a vector; we’ll use two of them: the L1L1L1 norm and the L2L2L2 norm.

L1 and L2 Norms¶

The L1L1L1 norm of a vector VVV of length kkk is defined as ∥V∥1=∑i=1k∣Vi∣\lVert V \rVert_1 = \sum_{i=1}^k \lvert V_i \rvert∥V∥1​=∑i=1k​∣Vi​∣ (i.e. it’s the sum of the vector’s elements). In 2-dimensional space, the L1L1L1 norm of the difference between two vectors yields the “manhattan distance” between them.

The L2L2L2 norm of a vector VVV of length kkk is defined as ∥V∥2=∑i=1kVi2\lVert V \rVert_2 = \sqrt{\sum_{i=1}^k V_i^2}∥V∥2​=∑i=1k​Vi2​​ (i.e. the square root of the sum of the squares). In 2-dimensional space, this is the “Euclidean distance”, and it’s always less than or equal to the L1L1L1 norm.

L1 and L2 Sensitivities¶

The L1L1L1 sensitivity of a vector-valued function fff is:

Definition 3 (L1 Sensitivity)
GS(f)=max⁡d(x,x′)≤1∥f(x)−f(x′)∥1\begin{align*} GS(f) = \max_{d(x,x') \leq 1} \lVert f(x) - f(x') \rVert_1 \end{align*}GS(f)=d(x,x′)≤1max​∥f(x)−f(x′)∥1​​
(4)

This is equal to the sum of the elementwise sensitivities. For example, if we define a vector-valued function fff that returns a length-kkk vector of 1-sensitive results, then the L1L1L1 sensitivity of fff is kkk.

Similarly, the L2L2L2 sensitivity of a vector-valued function fff is:

Definition 4 (L2 Sensitivity)
GS2(f)=max⁡d(x,x′)≤1∥f(x)−f(x′)∥2\begin{align*} GS_2(f) = \max_{d(x,x') \leq 1} \lVert f(x) - f(x') \rVert_2 \end{align*}GS2​(f)=d(x,x′)≤1max​∥f(x)−f(x′)∥2​​
(5)

Using the same example as above, a vector-valued function fff returning a length-kkk vector of 1-sensitive results has L2L2L2 sensitivity of k\sqrt{k}k​. For long vectors, the L2L2L2 sensitivity will obviously be much lower than the L1L1L1 sensitivity! For some applications, like machine learning algorithms (which sometimes return vectors with thousands of elements), L2L2L2 sensitivity is significantly lower than L1L1L1 sensitivity.

Choosing Between L1 and L2¶

As mentioned earlier, both the Laplace and Gaussian mechanisms can be extended to vector-valued functions. However, there’s a key difference between these two extensions: the vector-valued Laplace mechanism requires the use of L1L1L1 sensitivity, while the vector-valued Gaussian mechanism allows the use of either L1L1L1 or L2L2L2 sensitivity. This is a major strength of the Gaussian mechanism. For applications in which L2L2L2 sensitivity is much lower than L1L1L1 sensitivity, the Gaussian mechanism allows adding much less noise.

  • The vector-valued Laplace mechanism releases f(x)+(Y1,…,Yk)f(x) + (Y_1, \dots, Y_k)f(x)+(Y1​,…,Yk​), where YiY_iYi​ are drawn i.i.d. from the Laplace distribution with scale sϵ\frac{s}{\epsilon}ϵs​ and sss is the L1L1L1 sensitivity of fff

  • The vector-valued Gaussian mechanism releases f(x)+(Y1,…,Yk)f(x) + (Y_1, \dots, Y_k)f(x)+(Y1​,…,Yk​), where YiY_iYi​ are drawn i.i.d. from the Gaussian distribution with σ2=2s2log⁡(1.25/δ)ϵ2\sigma^2 = \frac{2s^2 \log(1.25/\delta)}{\epsilon^2}σ2=ϵ22s2log(1.25/δ)​ and sss is the L2L2L2 sensitivity of fff

The Catastrophe Mechanism¶

The definition of (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy says that a mechanism which satisfies the definition must “behave well” with probability 1−δ1-\delta1−δ. That means that with probability δ\deltaδ, the mechanism can do anything at all. This “failure probability” is concerning, because mechanisms which satisfy the relaxed definition may (with low probability) result in very bad outcomes.

Consider the following mechanism, which we will call the catastrophe mechanism:

Definition 5 (Catastrophe Mechanism)
F(q,x)=  Sample a number r from the uniform distribution between 0 and 1If r<δ,return xOtherwise, return q(x)+Lap(s/ϵ),where s is the sensitivity of q\begin{align*} F(q, x) =\;& \text{Sample a number $r$ from the uniform distribution between 0 and 1}\\ &\text{If } r < \delta, \text{return } x\\ &\text{Otherwise, return } q(x) + \text{Lap}(s/\epsilon), \text{where $s$ is the sensitivity of $q$}\\ \end{align*}F(q,x)=​Sample a number r from the uniform distribution between 0 and 1If r<δ,return xOtherwise, return q(x)+Lap(s/ϵ),where s is the sensitivity of q​
(6)

With probability 1−δ1-\delta1−δ, the catastrophe mechanism satisfies ϵ\epsilonϵ-differential privacy. With probability δ\deltaδ, it releases the whole dataset with no noise. This mechanism satisfies the definition of approximate differential privacy, but we probably wouldn’t want to use it in practice.

Fortunately, most (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differentially private mechanisms don’t have such a catastrophic failure mode. The Gaussian mechanism, for example, doesn’t ever release the whole dataset. Instead, with probability δ\deltaδ, the Gaussian mechanism doesn’t quite satisfy ϵ\epsilonϵ-differential privacy - it satisfies cϵc\epsiloncϵ-differential privacy instead, for some value ccc.

The Gaussian mechanism thus fails gracefully, rather than catastrophically, so it’s reasonable to have far more confidence in the Gaussian mechanism than in the catastrophe mechanism. Later, we will see alternative relaxations of the definition of differential privacy which distinguish between mechanisms that fail gracefully (like the Gaussian mechanism) and ones that fail catastropically (like the catastrophe mechanism).

Advanced Composition¶

We have already seen two ways of combining differentially private mechanisms: sequential composition and parallel composition. It turns out that (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy admits a new way of analyzing the sequential composition of differentially private mechanisms, which can result in a lower privacy cost.

The advanced composition theorem Dwork et al. (2010) is usually stated in terms of mechanisms which are instances of kkk-fold adaptive composition.

Definition 6 (Adaptive Composition)

A kkk-fold adaptive composition is a sequence of mechanisms m1,…,mkm_1, \dots, m_km1​,…,mk​ such that:

  • Each mechanism mim_imi​ may be chosen based on the outputs of all previous mechanisms m1,…,mi−1m_1, \dots, m_{i-1}m1​,…,mi−1​ (hence adaptive)

  • The input to each mechanism mim_imi​ is both the private dataset and all of the outputs of previous mechanisms (hence composition)

Iterative programs (i.e. loops or recursive functions) are nearly always instances of kkk-fold adaptive composition. A for loop that runs 1000 iterations, for example, is a 1000-fold adaptive composition. As a more specific example, an averaging attack is a kkk-fold adaptive composition:

# works for sensitivity-1 queries
def avg_attack(query, epsilon, k):
    results = [query + np.random.laplace(loc=0, scale=1/epsilon) for i in range(k)]
    return np.mean(results)

avg_attack(10, 1, 500)

In this example, the sequence of mechanisms is fixed ahead of time (we use the same mechanism each time), and k=500k = 500k=500.

The standard sequential composition theorem says that the total privacy cost of this mechanism is kϵk\epsilonkϵ (in this case, 500ϵ500 \epsilon500ϵ).

The advanced composition theorem says:

Theorem 2 (Advanced Composition)

Advanced Composition Theorem¶

The Advanced Composition Theorem quantifies how privacy degrades when multiple differentially private mechanisms are applied to the same dataset. Specifically, it provides a tighter bound on the cumulative privacy loss than simple (linear) composition.

Let A1,…,Ak\mathcal{A}_1, \dots, \mathcal{A}_kA1​,…,Ak​ be randomized mechanisms, each satisfying (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy. Then, for any δ′>0\delta' > 0δ′>0, the mechanism that applies all kkk of these mechanisms (possibly adaptively) satisfies:

(ϵ′,kδ+δ′)-differential privacy\left( \epsilon', k \delta + \delta' \right)\text{-differential privacy}(ϵ′,kδ+δ′)-differential privacy
(7)

where

ϵ′=2kln⁡(1/δ′)⋅ϵ+kϵ(eϵ−1)\epsilon' = \sqrt{2k \ln(1/\delta')} \cdot \epsilon + k\epsilon(e^\epsilon - 1)ϵ′=2kln(1/δ′)​⋅ϵ+kϵ(eϵ−1)
(8)

In the special case where ϵ\epsilonϵ is small (e.g., ϵ<1\epsilon < 1ϵ<1), the expression simplifies and is often approximated as:

ϵ′≈2kln⁡(1/δ′)⋅ϵ\epsilon' \approx \sqrt{2k \ln(1/\delta')} \cdot \epsilonϵ′≈2kln(1/δ′)​⋅ϵ
(9)

This theorem demonstrates that the cumulative privacy loss grows sublinearly in kkk, meaning that running more private computations doesn’t degrade privacy as quickly as naive summation would suggest. However, δ\deltaδ does grow linearly, which still imposes practical limits on repeated use of private mechanisms.

import numpy as np
import matplotlib.pyplot as plt

# Fixed parameters
epsilon = 0.1          # base epsilon
delta = 1e-5           # base delta for each mechanism
delta_prime = 1e-6     # additional delta for advanced composition

# Range of composition depths
k_values = np.arange(1, 201)

# Advanced composition epsilon'
def advanced_composition(eps, k, delta_prime):
    term1 = np.sqrt(2 * k * np.log(1 / delta_prime)) * eps
    term2 = k * eps * (np.exp(eps) - 1)
    return term1 + term2

eps_advanced = advanced_composition(epsilon, k_values, delta_prime)

# Naive composition epsilon'
eps_naive = epsilon * k_values

# Plot
plt.figure(figsize=(8, 5))
plt.plot(k_values, eps_advanced, label='Advanced Composition', color='blue')
plt.plot(k_values, eps_naive, label='Naive Composition', color='red', linestyle='--')

plt.xlabel('Number of Compositions $k$')
plt.ylabel(r'Composed Privacy Budget $\epsilon^\prime$')
plt.title(r'Naive vs. Advanced Composition $(\epsilon=0.1, \delta=10^{-5})$')
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()

The red dashed line (naive composition) shows linear growth. The blue curve (advanced composition) grows more slowly due to sublinear behavior of the square root term. This demonstrates how advanced composition can significantly improve privacy accounting in multi-query settings.

So advanced composition derives a much lower bound on ϵ′\epsilon'ϵ′ than sequential composition, for the same mechanism. What does this mean? It means that the bounds given by sequential composition are loose - they don’t tightly bound the actual privacy cost of the computation. In fact, advanced composition also gives loose bounds - they’re just slightly less loose than the ones given by sequential composition.

It’s important to note that the two bounds are technically incomparable, since advanced composition introduces a δ\deltaδ. When δ\deltaδ is small, however, we will often compare the ϵ\epsilonϵs given by both methods.

Standard sequential composition, it turns out, beats advanced composition for kkk smaller than about 37. Thus, advanced composition is only really useful when kkk is large (e.g. more than 100). When kkk is very large, though, advanced composition can make a big difference!

Advanced Composition for Approximate Differential Privacy¶

The description of advanced composition above requires the individual mechanisms being composed to satisfy pure ϵ\epsilonϵ-differential privacy. However, the theorem also applies if they satisfy (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy instead. The more general statement of the advanced composition theorem is as follows (Dwork et al. (2010), Theorem 3.20):

Theorem 3 (Approximate Advanced Composition)

  • If each mechanism mim_imi​ in a kkk-fold adaptive composition m1,…,mkm_1, \dots, m_km1​,…,mk​ satisfies (ϵ,δ)(\epsilon, \delta)(ϵ,δ)-differential privacy

  • Then for any δ′≥0\delta' \geq 0δ′≥0, the entire kkk-fold adaptive composition satisfies (ϵ′,kδ+δ′)(\epsilon', k\delta + \delta')(ϵ′,kδ+δ′)-differential privacy, where:

ϵ′=ϵ2kln⁡(1/δ′)+kϵ(eϵ−1)\begin{align} \epsilon' = \epsilon \sqrt{2k \ln(1/\delta')} + k \epsilon (e^{\epsilon} - 1) \end{align}ϵ′=ϵ2kln(1/δ′)​+kϵ(eϵ−1)​​
(10)

The only difference is in the failure parameter δ\deltaδ for the composed mechanism, where we have an additional kδk\deltakδ term. When the mechanisms being composed satisfy pure ϵ\epsilonϵ-differential privacy, then δ=kδ=0\delta = k\delta = 0δ=kδ=0, and we get the same result as the statement above.

Summary

  • For applications in which L2 sensitivity is much lower than L1 sensitivity, the Gaussian mechanism allows adding much less noise.

  • When the number of iterations in a loop is very large, advanced composition can make a big difference in accuracy.
