近似差分隐私

学习目标

阅读本章后，您将能够：

  • 定义近似差分隐私

  • 解释近似差分隐私和纯粹差分隐私的区别

  • 描述近似差分隐私的优势和劣势

  • 描述和计算向量值查询的L1和L2敏感度

  • 定义和使用高斯机制

  • 应用高级组合性

近似差分隐私（Approximate Differential Privacy）Dwork et al. (2006)，也称(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私，其定义如下所述：

Pr[F(x)=S]≤eϵPr[F(x′)=s]+δ\begin{align} \mathsf{Pr}[F(x) = S] \leq e^\epsilon \mathsf{Pr}[F(x') = s] + \delta \end{align}Pr[F(x)=S]≤eϵPr[F(x′)=s]+δ​​
(1)

新出现的隐私参数δ\deltaδ表示不满足此近似差分隐私定义的"失败概率"。我们有1−δ1-\delta1−δ的概率获得等价于纯粹差分隐私的隐私保护程度。同时，我们有δ\deltaδ的概率不满足隐私参数为ϵ\epsilonϵ的纯粹差分隐私。换句话说：

  • 满足Pr[F(x)=S]Pr[F(x′)=s]≤eϵ\frac{\mathsf{Pr}[F(x) = S]}{\mathsf{Pr}[F(x') = s]} \leq e^\epsilonPr[F(x′)=s]Pr[F(x)=S]​≤eϵ的概率为1−δ1-\delta1−δ

  • 不能保证满足上述不等式的概率为δ\deltaδ

上述定义看起来有点吓人！我们有δ\deltaδ的概率无法保证差分隐私，这意味着我们甚至可能有δ\deltaδ的概率泄露整个敏感数据集！因此，我们通常要求δ\deltaδ很小。一般来说，我们要求δ\deltaδ的取值小于等于1n2\frac{1}{n^2}n21​，其中nnn表示数据集的总大小。此外，我们还将看到，实际使用的(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私机制不会像定义所描述的那样吓人，不会出现一旦失败就引发灾难性后果的情况。实际上，该机制会温和地失败，一般不会造成诸如泄露整个数据集之类的严重后果。

确实可以构造出此类机制，并可以证明构造出的机制确实满足(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私。我们将在本章后续部分看到实际的机制构造方法。

近似差分隐私的性质¶

近似差分隐私拥有和纯粹ϵ\epsilonϵ-差分隐私相似的特性。它同样满足串行组合性：

  • 如果F1(x)F_1(x)F1​(x)满足(ϵ1,δ1)(\epsilon_1, \delta_1)(ϵ1​,δ1​)-差分隐私

  • 同时F2(x)F_2(x)F2​(x)满足(ϵ2,δ2)(\epsilon_2, \delta_2)(ϵ2​,δ2​)-差分隐私

  • 则发布两个结果的机制G(x)=(F1(x),F2(x))G(x) = (F_1(x), F_2(x))G(x)=(F1​(x),F2​(x))满足(ϵ1+ϵ2,δ1+δ2)(\epsilon_1+\epsilon_2, \delta_1 + \delta_2)(ϵ1​+ϵ2​,δ1​+δ2​)-差分隐私

与纯粹ϵ\epsilonϵ-差分隐私相比，近似差分隐私串行组合性唯一的不同之处在于需要分别对δ\deltaδ和ϵ\epsilonϵ相加。近似差分隐私同样满足后处理性和并行组合性。

高斯机制¶

可以用高斯机制替代拉普拉斯机制。高斯机制增加的不是拉普拉斯噪声，而是高斯噪声。高斯机制无法满足纯粹ϵ\epsilonϵ-差分隐私，但可以满足(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私。对于一个返回数值的函数f(x)f(x)f(x)，应用下述定义的高斯机制，可以得到满足(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私的F(x)F(x)F(x)：

F(x)=f(x)+N(σ2)where σ2=2s2log⁡(1.25/δ)ϵ2\begin{align} F(x) = f(x) + \mathcal{N}(\sigma^2)\\ \text{where } \sigma^2 = \frac{2s^2 \log(1.25/\delta)}{\epsilon^2} \end{align}F(x)=f(x)+N(σ2)where σ2=ϵ22s2log(1.25/δ)​​​
(2)

其中sss是fff的敏感度，N(σ2)\mathcal{N}(\sigma^2)N(σ2)表示均值为0，方差为σ2\sigma^2σ2的高斯（正态）分布采样结果。请注意，这里的log⁡\loglog表示自然对数（本书其他地方出现的log⁡\loglog同样表示自然对数）。

对于实值函数f:D→Rf : D \rightarrow \mathbb{R}f:D→R，我们可以按照与拉普拉斯机制完全相同的方法使用高斯机制。在相同的ϵ\epsilonϵ取值下，很容易对比两种机制的应用效果。

因此，高斯机制有两个严重的缺点：其一，该机制需要使用宽松的(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私定义；其二，该机制的准确性不如拉普拉斯机制。既然如此，为什么我们还需要高斯机制呢？

向量值函数及其敏感度¶

截至目前，我们考虑的都是实值函数（即输出总为单一实数的函数）。此类函数的形式为：f:D→Rf : D \rightarrow \mathbb{R}f:D→R。拉普拉斯机制和高斯机制都可以扩展到形式为：f:D→Rkf : D \rightarrow \mathbb{R}^kf:D→Rk的向量值函数，即输出为实数向量的函数。我们可以将直方图看作向量值函数，其返回的向量表示直方图各个分箱的计数值。

我们在前面提到，函数的敏感度定义为：

GS(f)=max⁡d(x,x′)≤1∣f(x)−f(x′)∣\begin{align} GS(f) = \max_{d(x,x') \leq 1} \lvert f(x) - f(x') \rvert \end{align}GS(f)=d(x,x′)≤1max​∣f(x)−f(x′)∣​​
(3)

我们如何定义向量值函数的敏感度呢？

考虑表达式f(x)−f(x′)f(x) - f(x')f(x)−f(x′)。如果fff是向量值函数，那么该表达式表示的是两个向量之间的差，可以通过计算对应位置元素之间的差来得到（两个长度为kkk的向量差是一个长度为kkk的新向量）。这个新向量就是f(x)f(x)f(x)和f(x′)f(x')f(x′)之间的距离。

该向量的标量长度就是fff的敏感度。有很多计算向量标量长度的方法。我们将使用两种方法：L1L1L1范数和L2L2L2范数。

L1和L2范数¶

给定长度为kkk的向量VVV，其L1L1L1范数定义为∥V∥1=∑i=1k∣Vi∣\lVert V \rVert_1 = \sum_{i=1}^k \lvert V_i \rvert∥V∥1​=∑i=1k​∣Vi​∣（即向量各个元素的和）。在二维空间中，两个向量之差的L1L1L1范数就是它们的"曼哈顿距离"。

给定长度为kkk的向量VVV，其L2L2L2范数定义为∥V∥2=∑i=1kVi2\lVert V \rVert_2 = \sqrt{\sum_{i=1}^k V_i^2}∥V∥2​=∑i=1k​Vi2​​（即向量各个元素平方和再求平方根）。在二维空间中，两个向量之差的L2L2L2范数就是它们的"欧氏距离"。L2L2L2范数总是小于或等于L1L1L1范数。

L1和L2敏感度¶

向量值函数fff的L1L1L1敏感度为：

GS(f)=max⁡d(x,x′)≤1∥f(x)−f(x′)∥1\begin{align} GS(f) = \max_{d(x,x') \leq 1} \lVert f(x) - f(x') \rVert_1 \end{align}GS(f)=d(x,x′)≤1max​∥f(x)−f(x′)∥1​​​
(4)

此敏感度等于向量各个元素敏感度的和。举例来说，如果我们定义了一个向量值函数fff，其返回一个长度为kkk的向量，且向量中各个元素的敏感度均为1，则fff的L1L1L1敏感度为kkk。

类似地，向量值函数fff的L2L2L2敏感度为：

GS2(f)=max⁡d(x,x′)≤1∥f(x)−f(x′)∥2\begin{align} GS_2(f) = \max_{d(x,x') \leq 1} \lVert f(x) - f(x') \rVert_2 \end{align}GS2​(f)=d(x,x′)≤1max​∥f(x)−f(x′)∥2​​​
(5)

同样是上述的例子，向量值函数fff返回一个长度为kkk的向量，且向量中各个元素的敏感度均为1，则fff的L2L2L2敏感度为k\sqrt{k}k​。对于长向量，L2L2L2敏感度显然比L1L1L1敏感度低得多！在机器学习算法（返回的向量有时包含成千上万个元素）等应用中，L2L2L2敏感度显著低于L1L1L1敏感度。

选择L1还是L2¶

如之前所述，拉普拉斯机制和高斯机制都可以扩展到向量值函数。然而，这两种机制的扩展结果间有一个关键差异点：向量值拉普拉斯机制需要使用L1L1L1敏感度，而向量值高斯机制既可以使用L1L1L1敏感度，也可以使用L2L2L2敏感度。这是高斯机制的一个重要优势。对于L2L2L2敏感度远低于L1L1L1敏感度的应用来说，高斯机制添加的噪声要小得多。

  • 向量拉普拉斯机制发布的是f(x)+(Y1,…,Yk)f(x) + (Y_1, \dots, Y_k)f(x)+(Y1​,…,Yk​)，其中YiY_iYi​是采样自拉普拉斯分布的独立同分布噪声，噪声尺度为sϵ\frac{s}{\epsilon}ϵs​，其中sss是fff的L1L1L1敏感度。

  • 向量高斯机制发布的是f(x)+(Y1,…,Yk)f(x) + (Y_1, \dots, Y_k)f(x)+(Y1​,…,Yk​)，其中YiY_iYi​是采样自高斯分布的独立同分布噪声，且σ2=2s2log⁡(1.25/δ)ϵ2\sigma^2 = \frac{2s^2 \log(1.25/\delta)}{\epsilon^2}σ2=ϵ22s2log(1.25/δ)​，其中sss是fff的L2L2L2的敏感度。

灾难机制¶

(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私定义称，满足此差分隐私定义的机制必须以1−δ1-\delta1−δ的概率"表现良好"。但这也意味着此机制可以有δ\deltaδ的概率执行任何操作。"失败概率"的存在令人无比担忧，因为满足宽松定义的差分隐私机制总可能（即使发生的概率很低）给出糟糕的输出结果。

考虑如下机制，我们称之为灾难机制（Catastrophe Mechanism）：

F(q,x)=  在0到1之间均匀随机地采样得到一个数r如果 r<δ,返回 x否则，返回 q(x)+Lap(s/ϵ),其中s是q的敏感度\begin{align} F(q, x) =\;& \text{在0到1之间均匀随机地采样得到一个数$r$}\\ &\text{如果 } r < \delta, \text{返回 } x\\ &\text{否则，返回 } q(x) + \text{Lap}(s/\epsilon), \text{其中$s$是$q$的敏感度}\\ \end{align}F(q,x)=​在0到1之间均匀随机地采样得到一个数r如果 r<δ,返回 x否则，返回 q(x)+Lap(s/ϵ),其中s是q的敏感度​​
(6)

灾难机制有1−δ1-\delta1−δ的概率满足ϵ\epsilonϵ-差分隐私。然而，灾难机制同时有δ\deltaδ的概率泄露无噪声的整个数据集。尽管该机制满足近似差分隐私定义，但我们在实际中不太可能会应用此机制。

幸运的是，大多数(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私机制不会出现类似的灾难性失效情况。例如，高斯机制就不会真的发布整个数据集。高斯机制只是有δ\deltaδ的概率不会严格地满足ϵ\epsilonϵ-差分隐私，而是满足某个值ccc下的cϵc\epsiloncϵ-差分隐私。

因此，高斯机制会很温和地失败，而不会灾难性地失败。因此，与灾难机制相比，我们有理由相信高斯机制可以为我们提供更好的隐私保护。我们后续还将看到差分隐私的另一种宽松定义方法。此定义可以区分温和性失败机制（如高斯机制）和灾难性失败机制（如灾难机制）。

高级组合性¶

我们已经学习了差分隐私机制的两种组合方式：串行组合性和并行组合性。事实证明，(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私引入了差分隐私机制串行组合性的一种新分析方法，此分析方法可以进一步降低隐私消耗量。

高级组合定理Dwork et al. (2010)通常用kkk-折叠适应性组合（kkk-fold Adaptive Composition）机制来描述。kkk-折叠适应性组合指的是将一系列机制m1,…,mkm_1, \dots, m_km1​,…,mk​组合起来，这些机制满足下述条件：

  • 适应性：可以根据所有前述机制m1,…,mi−1m_1, \dots, m_{i-1}m1​,…,mi−1​的输出来选择下一个机制mim_imi​

  • 组合性：每个机制mim_imi​的输入既包括隐私数据集，也包括前述机制的所有输出

迭代程序（如循环或递归函数）几乎都是kkk-折叠适应性组合的实例。例如，一个执行1000轮的for循环是1000-折叠适应性组合。再举一个更特殊的例子，平均攻击也是kkk-折叠适应性组合：

# 此攻击针对的是敏感度为1的问询
def avg_attack(query, epsilon, k):
    results = [query + np.random.laplace(loc=0, scale=1/epsilon) for i in range(k)]
    return np.mean(results)

avg_attack(10, 1, 500)

标准串行组合定理称，该机制的总隐私消耗量为kϵk\epsilonkϵ（本例的总隐私消耗量为500ϵ500 \epsilon500ϵ）。

高级组合定理称：

  • 如果kkk-折叠适应性组合m1,…,mkm_1, \dots, m_km1​,…,mk​中的每一个机制mim_imi​都满足ϵ\epsilonϵ-差分隐私

  • 则对于任意δ≥0\delta \geq 0δ≥0，整个kkk-折叠适应性组合满足(ϵ′,δ′)(\epsilon', \delta')(ϵ′,δ′)-差分隐私，其中：

ϵ′=ϵ2kln⁡(1/δ′)+kϵ(eϵ−1)\begin{align} \epsilon' = \epsilon \sqrt{2k \ln(1/\delta')} + k \epsilon (e^{\epsilon} - 1) \end{align}ϵ′=ϵ2kln(1/δ′)​+kϵ(eϵ−1)​​
(7)

根据前面的例子，将ϵ=1\epsilon = 1ϵ=1代入到表达式中，并设置δ′=10−5\delta' = 10^{-5}δ′=10−5，我们有：

ϵ′=1000ln⁡(100000)+500×(e−1)≈966.44\begin{align} \epsilon' =& \sqrt{1000 \ln(100000)} + 500 \times (e - 1)\\ \approx& 966.44 \end{align}ϵ′=≈​1000ln(100000)​+500×(e−1)966.44​​
(8)

因此，对于相同机制，应用高级组合性得到的ϵ′\epsilon'ϵ′下界远低于应用串行组合性得到的下界。这意味着什么呢？这意味着串行组合性得到的隐私消耗量下界是宽松的。与实际隐私消耗相比，串行组合性得到的下界不够紧致。事实上，高级组合性得到的下界也是宽松的，此下界只是比串行组合性给出的下界稍显紧致一些。

需要着重强调的是，得到的两种隐私消耗量上界在技术角度看不具有可比性，因为高级组合性引入了δ\deltaδ。但当δ\deltaδ很小时，我们通常可以比较两种方法给出的ϵ\epsilonϵ。

既然如此，我们应该总是使用高级组合性吗？并非如此。我们分别对于不同的kkk值计算隐私消耗量，绘制串行组合性和高级组合性的总隐私消耗图。

近似差分隐私的高级组合性¶

当使用高级组合性时，前述要求各个机制均需满足纯粹ϵ\epsilonϵ-差分隐私。然而，如果各个机制满足(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私，高级组合定理同样适用。高级组合定理更一般的描述如下（Dwork et al. (2010), 定理3.20）：

  • 如果kkk-折叠适应性组合m1,…,mkm_1, \dots, m_km1​,…,mk​中的每个机制mim_imi​都满足(ϵ,δ)(\epsilon, \delta)(ϵ,δ)-差分隐私

  • 则对于任意δ′≥0\delta' \geq 0δ′≥0，整个kkk-折叠适应性组合都满足(ϵ′,kδ+δ′)(\epsilon', k\delta + \delta')(ϵ′,kδ+δ′)-差分隐私，其中：

ϵ′=ϵ2kln⁡(1/δ′)+kϵ(eϵ−1)\begin{align} \epsilon' = \epsilon \sqrt{2k \ln(1/\delta')} + k \epsilon (e^{\epsilon} - 1) \end{align}ϵ′=ϵ2kln(1/δ′)​+kϵ(eϵ−1)​​
(9)

与前面的描述相比，唯一的区别是组合机制的失败参数δ\deltaδ，即这里的失败参数包含额外的kδk\deltakδ项。当待组合的机制满足纯粹ϵ\epsilonϵ-差分隐私时，我们有δ=kδ=0\delta = k\delta = 0δ=kδ=0。两种描述在纯粹差分隐私下得到的结果一致。
